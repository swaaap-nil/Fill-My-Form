Form Agent test fixtures

Local fixtures for form detection and filling. Automated tests must never depend on a third-party website.

  • simple.html — well-formed, labelled, every common control
  • image-max-size.html — labelled image upload with a byte limit
  • generic-upload.html — file pickers with no resume/photo/signature alias
  • messy.html — no labels, placeholder-only, ambiguous names
  • ibps-like.html — nested file upload with generic picker text
  • aai-copied.html — copied AAI photo/signature upload page
  • aai-more.html — copied AAI non-upload application page
  • dynamic.html — fields appear after load and between steps
  • controlled.html — React-controlled, masked, custom combobox, format-strict date
